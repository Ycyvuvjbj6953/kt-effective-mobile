# Тестовое задание: Системный аналитик (Effective Mobile)

## О репозитории
Решение тестового задания на позицию Junior системный аналитик от компании Effective Mobile (2025). 
Исходное задание взято из открытого источника: [https://github.com/yanalaska-analyst/effective-mobile-test-sa](https://github.com/yanalaska-analyst/effective-mobile-test-sa).

## Что сделано
* **Задание 1 (Анализ требований):** Проведен анализ фрагмента ТЗ для функционала "Корзина" интернет-магазина. Найдены логические противоречия и недочеты, предложена исправленная версия ТЗ, а также составлены уточняющие вопросы к продукт-менеджеру.
* **Задание 2 (Проектирование API):** Спроектирован REST API (метод GET) для экрана отображения магазинов-партнеров в мобильном приложении. Написана спецификация полей и приведен пример JSON-ответа в соответствии с макетом.

## Что не сделано и почему
* **Задание 3 (Схема архитектуры push-уведомлений):** Задание не реализовано в рамках данного этапа. Основной фокус сделан на текстовой аналитике и проектировании REST API, так как это соответствует основному сценарию работы аналитика. На изучение специфики работы шлюзов и отрисовку корректной микросервисной архитектуры потребовалось бы дополнительное время.

## Как читать решение
Все артефакты находятся в папке `docs/`. Порядок для чтения:
1. `docs/task1_1_contradictions.md` — выявленные логические противоречия и недочеты в исходном ТЗ корзины.
2. `docs/task1_2_fixed_tz.md` — исправленная версия фрагмента ТЗ.
3. `docs/task1_3_questions.md` — уточняющие вопросы к продукт-менеджеру.
4. `docs/task2_api.md` — REST API для экрана магазинов-партнеров.
